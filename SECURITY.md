# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Older commits and forks are not
supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[piotr.wrobel@quadrantive.com](mailto:piotr.wrobel@quadrantive.com) with a description,
reproduction steps, affected routes or components, and the potential impact.

Do not include production credentials, private keys, seed phrases, or real user financial data.
You can expect an acknowledgement within seven days. Please allow reasonable time for a fix
before publishing details.

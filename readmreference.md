# Steel Deal Platform
Welcome to the Steel Deal Platform repository! This is the official steel auction platform, where buyers can connect to trade various types of steel products in a secure and transparent environment.

## Introduction
The Steel Deal Website is a central hub that provides easy information and access to our steel auction platform. Whether you are a steel buyer seeking top-quality steel products, this platform is designed to streamline the auction process and facilitate efficient transactions.

## Technologies
#### The Steel Deal Website and Steel Deal Auction platform are built using the following technologies:
* <b>Frontend</b>: Typescript, React.js, Vite, styled-components, TanStack
* <b>Backend</b>: Typescript, NestJS, PrismaORM, Swagger, OpenAPI-Typescript
* <b>Database</b>: PostgreSQL
* <b>Real-time Updates</b>: WebSocket

## Installation
Clone the repository
```
git clone https://github.com/ajiiz/steeldeal-platform
cd steeldeal-platform
```
Install dependencies
```
yarn install
```
Start the project
```
yarn dev
```
